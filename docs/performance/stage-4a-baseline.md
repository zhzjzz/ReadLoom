## 解释边界

- 普通测试书很小，12.8 ms 不能外推到磁盘较慢、entry 很多或接近 512 MiB 上限的 EPUB。
- 64 MiB 样本主要测流复制与摘要复验，不包含复杂 XML、数千资源或杀毒软件扫描波动。
- UI 保存约 0.86–0.90 秒，其中包含原生对话框自动化、前端等待、Rust 重打包、复验、原子提交和重新打开，不能与纯 Rust 探针直接比较。
- 没有安装器、没有清空系统缓存，也没有第三方 EPUBCheck，因此不提供相应数字。
