## 解释边界

- 一个打开的 EPUB 会新增 sandbox OOPIF/渲染工作，WebView2 进程树内存明显高于空白页；数字包含共享运行时，不等于 Rust 独占内存。
- 章节按需读取和净化，应用不会一次构建全书 DOM，也不会把整本书解压到磁盘。
- 搜索逐个读取线性 spine，结果有上限并可取消，但阶段 3 不建立持久全文索引。
- 测试脚本关闭每个由它启动的进程；最终关闭路径 exit code 为 0。
