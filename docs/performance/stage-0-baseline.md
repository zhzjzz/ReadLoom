| 2 | 489.07 ms | 454 ms | 7 | 389,885,952 B | 227,807,232 B |

- 首次启动代理值：717.75 ms。
- 后四次启动中位数：494.57 ms。
- 五次 Rust 主进程就绪中位数：466 ms。
- 五次空闲工作集中位数：390,209,536 B（372.13 MiB）。
- 五次空闲私有内存中位数：229,228,544 B（218.61 MiB）。

## 解释边界

- “首次启动代理值”是 release 构建完成后的第一次采样，没有清空 Windows 文件缓存，也没有重启系统，因此不是严格意义上的冷启动。
- 空闲内存包含共享 WebView2 运行时的 Readloom 进程树；不同 WebView2 版本、系统服务状态和安全软件会改变结果。
- 脚本会结束每轮由它启动的 Readloom 进程树，不保留后台实例。
- 后续阶段应使用同一环境、同一脚本和同一等待时长复测，优先看相对变化。
